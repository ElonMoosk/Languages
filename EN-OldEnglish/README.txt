EN-OldEnglish — Old English (Englisc) language pack for Juno: New Origins
=========================================================================

Install
-------
1. Copy the whole EN-OldEnglish folder into:
   %USERPROFILE%\AppData\LocalLow\Jundroo\SimpleRockets 2\Languages\
2. Start Juno: New Origins.
3. Open Settings > Language and choose "Englisc".
4. Restart the game if the language does not appear immediately.

Contents
--------
- Strings.xml   — UI text in deliberately obscure late West Saxon Old English
- Fonts.xml     — font configuration
- Junicode.ttf  — Junicode Two Beta Regular
- OFL.txt       — SIL Open Font License 1.1 for Junicode

Notes
-----
- Vizzy entries remain in English so the programming interface stays usable.
- Multiplayer and HorseEye add-on strings are not included; the game falls back
  to the English originals for those.
- This is a literary, intentionally difficult Old English rendering, not a
  scholarly edition. Technical terms are often calqued with Old English roots.
- The font is licensed under the SIL Open Font License 1.1; keep OFL.txt with it.
